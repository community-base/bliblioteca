Para gerar a capa, o arquivo precisa estar disponível diretamente em PDF com autorização de acesso pelo navegador (CORS). Links de visualização do Google Drive podem permitir leitura, mas bloquear a extração da capa.

Importar PDFs públicos do GitHub

O aplicativo examina os arquivos PDF de um repositório público, incluindo subpastas, usando a API pública do GitHub. Limite de 100 PDFs por importação. Repositórios privados exigem outra solução autenticada.
